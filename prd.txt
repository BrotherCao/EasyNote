# EasyNote - 轻量级自用笔记软件 PRD

## 1. 产品定位
一款面向个人自用的轻量级 Markdown 笔记桌面应用（Windows）。核心卖点：
**"悬浮小窗 + 不抢焦点"** —— 让用户在阅读 PDF/网页/任意内容时，随时随手记下笔记，
小窗始终置顶、点击屏幕其他区域不会消失，实现"边读边记"的流畅体验。

## 2. 技术选型
| 层 | 选型 | 理由 |
|---|---|---|
| 应用框架 | Tauri 2 (Rust + Webview) | 安装包 <10MB，原生窗口控制，always-on-top 完美支持浮窗 |
| 前端 | Svelte + TypeScript + Vite | 体积小、无虚拟 DOM 开销、编译产物小 |
| Markdown 编辑器 | 原生 textarea（v1 不引入重型编辑器） | 自用场景，简单够用，后续可换 CodeMirror |
| Markdown 渲染 | markdown-it | 轻量、插件化、社区活跃 |
| 全局快捷键 | tauri-plugin-global-shortcut | 系统级热键，应用未聚焦也能触发 |
| 文件系统 | tauri-plugin-fs | 原生读写 .md 文件与文件夹 |
| 窗口状态 | tauri-plugin-window-state | 记住窗口位置/大小 |

## 3. 功能清单（v1）

### 3.1 IN SCOPE（必须实现）
- [F1] Markdown 编辑：textarea 编辑，支持完整 Markdown 语法输入
- [F2] Markdown 预览：实时分屏预览（左编辑/右预览），所见即所得
- [F3] 文件读写：笔记以 `.md` 文件存储在用户选择的根目录下
- [F4] 文件夹管理：新建文件夹、删除文件夹、文件夹名称自定义
- [F5] 笔记管理：在文件夹内新建笔记、删除笔记、重命名笔记
- [F6] 悬浮小窗：独立的 always-on-top 窗口，无边框、不显示在任务栏
  - 点击屏幕其他区域（PDF、浏览器等）小窗不消失、不失去置顶
  - 全局快捷键 Ctrl+Shift+N 切换显隐
  - 可拖动、可调整大小
  - 内含一个精简编辑器 + 即时保存到"快速笔记"文件夹
- [F7] 自动保存：失焦时自动保存当前笔记
- [F8] 最近打开：主窗口侧栏显示最近编辑的 10 条笔记
- [F9] 暗色模式：跟随系统 / 手动切换

### 3.2 OUT OF SCOPE（v1 明确不做）
- 多设备同步 / 云存储
- 端到端加密
- 插件系统 / 第三方扩展
- 双链 / 反向链接（Backlinks）—— Obsidian 级功能过重
- 全文搜索（v2 再考虑）
- 图片粘贴 / 附件管理
- 多用户 / 协作
- 移动端 / 网页端
- PDF 标注 / 高亮

## 5. 交互细节
| 交互 | 行为 |
|---|---|
| 全局 Ctrl+Shift+N | 切换悬浮小窗显隐（应用未聚焦也生效） |
| 主窗口点击笔记 | 加载到编辑器，预览同步刷新 |
| 编辑器输入 | 防抖 500ms 后自动保存 + 预览刷新 |
| 编辑器失焦 | 立即保存 |
| 新建笔记 | 在当前文件夹创建 `未命名.md`，进入重命名 |
| 删除笔记 | 弹出确认，删除文件 |
| 新建文件夹 | 在根目录或选中文件夹下创建，名称可自定义 |
| 删除文件夹 | 确认后递归删除（含内部文件） |
| 悬浮窗拖动 | 拖动自定义标题栏移动窗口 |
| 悬浮窗点击外部 | **不消失**，保持 always-on-top 显示 |

## 6. 磁盘文件结构
```
<EasyNote根目录>/               ← 用户首次启动时选择
├── 工作/
│   ├── 会议纪要.md
│   └── 周报.md
├── 学习/
│   └── 读书笔记/
│       └── 深度工作.md
└── 快速笔记/                   ← 悬浮窗默认保存位置
    └── 2026-08-24-153000.md    ← 按时间戳命名
```
- 根目录路径持久化在 app config（`$APPDATA/easynote/config.json`）
- 所有笔记都是纯 .md 文件，可用任何编辑器打开，无锁定

## 7. 成功标准（验收）
1. 双击 .exe 启动应用，无报错，进入主界面
2. 首次启动提示选择根目录，选择后配置持久化
3. 能新建/删除文件夹，名称可自定义
4. 能在文件夹内新建/编辑/删除 .md 笔记
5. 编辑器输入 Markdown，预览区实时渲染（标题、列表、代码块、链接、表格）
6. 按 Ctrl+Shift+N 弹出悬浮小窗，小窗无边框、置顶、不在任务栏
7. 悬浮窗显示后，点击桌面其他窗口（如浏览器），悬浮窗不消失、保持置顶
8. 悬浮窗内输入内容，自动保存为 .md 文件在"快速笔记"文件夹
9. 关闭应用重开，文件夹/笔记列表、最近笔记、窗口位置恢复正常
10. 暗色模式可切换，渲染正常

## 8. 非功能要求
- 安装包体积 < 15MB（Tauri 基线）
- 冷启动 < 2 秒
- 笔记文件均为纯文本 .md，无数据库、无专有格式
- 单文件可执行，无需安装（portable .exe）
